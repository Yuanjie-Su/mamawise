# 妈妈智慧 (MamaWise)

妈妈智慧是一款专为孕妇设计的微信小程序，提供AI精准问答助手服务。它能够动态整合用户的健康记录，根据实时对话上下文生成个性化建议。

## 功能特点

- **AI精准问答**：基于用户健康记录和孕期阶段提供个性化建议
- **健康档案管理**：记录和跟踪孕期各项健康指标
- **简洁友好的界面**：采用柔和的色彩方案，操作简单直观

## 页面说明

1. **AI咨询**：与AI助手进行实时对话，获取个性化建议
2. **健康档案**：管理孕期各项健康指标，包括基本信息、体征记录、用药记录和产检记录
3. **个人中心**：用户信息和设置管理

## 技术实现

- 基于微信小程序开发框架
- 采用组件化、模块化的开发方式
- 使用CSS变量实现统一的主题色彩管理
- 模拟数据演示，实际应用中应对接后端API

## 开发与部署

### 开发环境

- 微信开发者工具
- Node.js

### 部署步骤

1. 克隆代码库
2. 在微信开发者工具中导入项目
3. 配置AppID
4. 开发完成后提交审核

## 项目结构
