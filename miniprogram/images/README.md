# 图片资源目录

此目录用于存放小程序所需的图片资源。

## 需要准备的图片

1. **头像图片**
   - default_avatar.png - 默认用户头像

2. **图标图片**
   - chat.png / chat_selected.png - 聊天图标
   - records.png / records_selected.png - 健康档案图标
   - profile.png / profile_selected.png - 个人中心图标
   - favorite.png - 收藏图标
   - help.png - 帮助图标
   - settings.png - 设置图标

## 图片规格建议

- 头像图片：建议使用正方形图片，尺寸为200x200像素
- 图标图片：建议使用正方形图片，尺寸为80x80像素
- 所有图片建议使用PNG格式，支持透明背景

## 注意事项

- 图片命名应与代码中引用的名称保持一致
- 图片大小应尽量优化，以减少小程序包体积
- 图片风格应统一，建议使用扁平化设计风格，颜色与应用主题色调一致
